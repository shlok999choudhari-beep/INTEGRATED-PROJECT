# EcoSort 386 – COA

## Computer Organization and Architecture

The **COA module** of EcoSort 386 demonstrates processor-level processing using **64-bit x86 Assembly Language**.

The implementation focuses on **CO2 – 64-bit Assembly Application Processing**, where numerical computations relevant to the EcoSort application are performed using registers, arithmetic instructions, comparison, and conditional branching.

---

## 📌 CO2 Objective

The CO2 implementation demonstrates:

- 64-bit Assembly programming
- Processing of 64-bit data
- Use of appropriate processor registers
- Arithmetic operations
- Comparison operations
- Conditional branching
- Application-related numerical processing

## 🧠 Registers Used

The implementation uses 64-bit x86 registers:

| Register | Purpose                                 |
| -------- | --------------------------------------- |
| `RAX`    | Main arithmetic operand and result      |
| `RCX`    | Second operand and function argument    |
| `RDX`    | Used during multiplication and division |

## 🔧 Assembly Instructions

| Instruction | Purpose                           |
| ----------- | --------------------------------- |
| `MOV`       | Loads data into registers         |

| `SUB`       | Performs subtraction              |
| `MUL`       | Performs multiplication           |
| `DIV`       | Performs division                 |
| `XOR`       | Clears a register before division |
| `CMP`       | Compares two values               |
| `JGE`       | Conditional branching             |
| `CALL`      | Calls an external function        |
| `RET`       | Returns from the program          |

## 🔢 Arithmetic Operations

### Addition

```asm
mov rax, 10
mov rcx, 5
add rax, rcx
```

Result:

```text
10 + 5 = 15 kg
```

### Subtraction

```asm
mov rax, 15
mov rcx, 10
sub rax, rcx
```

Result:

```text
15 - 10 = 5 kg
```

### Multiplication

```asm
mov rax, 15
mov rcx, 50
mul rcx
```

Result:

```text
15 × 50 = ₹750
```

### Division

```asm
mov rax, 15
mov rcx, 2
xor rdx, rdx
div rcx
```

Result:

```text
15 / 2 = 7 kg
```

---

## 🔀 Comparison and Conditional Branching

The program compares the total e-waste weight with a priority threshold.

```asm
mov rax, 15
cmp rax, 10
jge high_priority
```

The condition is:

```text
15 >= 10
```

Since the condition is true, execution branches to the `high_priority` label.

Output:

```text
Priority : HIGH PRIORITY
```
